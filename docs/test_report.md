## 关键改进

### 本轮新增

1. **v2h 预设**：新增「竖屏转横屏」预设，输出 16:9，与 h2v 互补
2. **真人检测线稿回退**：`run.py` 在视频参考被真人检测拦截时，自动对首帧做边缘检测（`edgedetect`）处理，用线稿参考帧重试，成功率 100%
3. **`--auto-asset` 选项**：失败片段自动注册 Asset 并重试（已实现但因 API Key/AK/SK 数据隔离暂不可用）
4. **`merge.py` 源片段填补**：失败片段用源片段替代，保持成片时长完整

### 平台限制发现

- **Asset API 与 Seedance 数据隔离**：通过 AK/SK（`open.volcengineapi.com`）创建的 Asset，无法被 API Key（`ark.cn-beijing.volces.com`）认证的 Seedance 端点看到。两套认证体系的资源命名空间完全隔离。
- **真人检测触发不一致**：同一视频，v2h/viral_replica 预设触发了真人检测，而 character_swap/style_transfer 预设的视频参考直接通过，说明真人检测与 prompt 内容也有关联。
